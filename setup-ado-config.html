If the automatic setup doesn't work, you can follow these steps to manually configure the ADO connection:

  1. Open the AI Scrum Agent application at http://localhost:3000
  2. Complete the setup wizard with the following information:
    • Organization: TR-Legal-Cobalt
    • Project: Legal Cobalt Backlog
    • Personal Access Token: Use the PAT from your .env.development file
    • API Version: 7.0
    • Team Name: Your exact team name as it appears in Azure DevOps
  3. After completing the setup, go to the dashboard to see your capacity data

Troubleshooting

If you still don't see capacity data after setting up the configuration:

  1. Make sure your Personal Access Token (PAT) has the necessary permissions:
    • Work Items (Read)
    • Project and Team (Read)
  2. Verify that your team name is exactly as it appears in Azure DevOps
  3. Check that capacity is set up for your team members in Azure DevOps
  4. Use the diagnostic tool in the application (Settings > Debug > ADO Capacity Diagnostics)
